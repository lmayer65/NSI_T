🐍 Cours Python — Héritage et polymorphisme

L'héritage est un mécanisme de la programmation orientée objet qui permet de créer une nouvelle classe à partir d'une classe existante.

Il permet de réutiliser du code, d'ajouter de nouvelles fonctionnalités et de spécialiser le comportement d'une classe.

1. Principe de l'héritage

1.1. Classe mère et classe fille

La classe existante est appelée classe mère ou classe parente. La nouvelle classe est appelée classe fille.

Une classe fille hérite des attributs et des méthodes de sa classe mère.

1.2. Exemple : une classe Personnage

class Personnage:
    def __init__(self, nom, vie, force):
        self.nom = nom
        self.vie = vie
        self.force = force

    def attaquer(self):
        print(self.nom, "attaque avec une arme.")

On crée maintenant un type particulier de personnage : un guerrier.

class Guerrier(Personnage):
    pass

La syntaxe class Guerrier(Personnage): indique que Guerrier hérite de Personnage. 

g = Guerrier("Conan", 100, 15)

print(g.nom)
print(g.vie)
g.attaquer()
Conan 100 Conan attaque avec une arme.

Même si la classe Guerrier est vide, elle possède les attributs et les méthodes hérités de Personnage.

2. Ajouter des attributs dans une classe fille

2.1. Utiliser super()

Une classe fille peut posséder des attributs supplémentaires. Par exemple, un guerrier peut avoir un attribut armure. 

class Guerrier(Personnage):
    def __init__(self, nom, vie, force, armure):
        super().__init__(nom, vie, force)
        self.armure = armure

L'instruction : 

super().__init__(nom, vie, force)

appelle le constructeur de la classe mère Personnage. Elle initialise donc les attributs :

  • self.nom
  • self.vie
  • self.force

Puis l'instruction suivante ajoute l'attribut spécifique au guerrier : 

self.armure = armure

2.2. Exemple

g = Guerrier("Conan", 100, 15, 20)

print(g.nom)
print(g.vie)
print(g.force)
print(g.armure)

3. Redéfinir une méthode

3.1. Principe

Une classe fille peut redéfinir une méthode héritée de sa classe mère.

Par exemple, l'attaque d'un guerrier peut être différente de celle d'un personnage ordinaire. 

class Guerrier(Personnage):
    def __init__(self, nom, vie, force, armure):
        super().__init__(nom, vie, force)
        self.armure = armure

    def attaquer(self):
        print(self.nom, "frappe avec son épée.")

La méthode attaquer() existait déjà dans la classe Personnage. Elle est ici redéfinie dans Guerrier. 

p = Personnage("Bob", 80, 10)
g = Guerrier("Conan", 100, 15, 20)

p.attaquer()
g.attaquer()
Bob attaque avec une arme. Conan frappe avec son épée.

4. Le polymorphisme

4.1. Une même méthode, plusieurs comportements

Le polymorphisme signifie qu'une même méthode peut produire des comportements différents selon la classe de l'objet. 

personnages = [
    Personnage("Bob", 80, 10),
    Guerrier("Conan", 100, 15, 20)
]

for personnage in personnages:
    personnage.attaquer()
Bob attaque avec une arme. Conan frappe avec son épée.

Python choisit automatiquement la version de la méthode attaquer() correspondant à la classe réelle de l'objet.

Résumé :
  • une classe fille hérite des attributs et méthodes de sa classe mère ;
  • super() permet d'appeler le constructeur de la classe mère ;
  • une méthode héritée peut être redéfinie dans une classe fille ;
  • le polymorphisme permet d'utiliser le même appel de méthode avec des comportements différents.

5. Exercice — Créer une classe Archer

On dispose des classes suivantes :

class Personnage:
    def __init__(self, nom, vie, force):
        self.nom = nom
        self.vie = vie
        self.force = force

    def attaquer(self):
        print(self.nom, "attaque avec une arme.")


class Guerrier(Personnage):
    def __init__(self, nom, vie, force, armure):
        super().__init__(nom, vie, force)
        self.armure = armure

    def attaquer(self):
        print(self.nom, "frappe avec son épée.")

Travail demandé :

  1. Créer une classe Archer qui hérite de Personnage.
  2. Ajouter à cette classe un attribut dexterite.
  3. Utiliser super() pour initialiser les attributs hérités de Personnage.
  4. Redéfinir la méthode attaquer() afin qu'elle affiche : « Legolas tire une flèche. »

On devra pouvoir créer un archer avec :

a = Archer("Legolas", 80, 10, 18)

Puis vérifier son comportement avec :

print(a.nom)
print(a.vie)
print(a.force)
print(a.dexterite)

a.attaquer()

Pour terminer : mettre en évidence le polymorphisme

p = Personnage("Bob", 80, 10)
g = Guerrier("Conan", 100, 15, 20)
a = Archer("Legolas", 80, 10, 18)

personnages = [p, g, a]

for personnage in personnages:
    personnage.attaquer()

Expliquer pourquoi l'instruction : 

personnage.attaquer()

est toujours la même alors que trois comportements différents sont obtenus.
