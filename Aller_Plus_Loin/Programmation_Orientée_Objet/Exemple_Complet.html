🌳 Exercice — Design pattern Composite

Objectifs : utiliser l'héritage, le polymorphisme et une structure récursive pour représenter un système de fichiers.

1. Situation

On souhaite représenter l'arborescence suivante :

NSI
├── cours.pdf
├── programme.py
└── Images
    ├── arbre.png
    └── graphe.png

2. Travail demandé

2.1. Classe mère

Créer une classe Element contenant une méthode afficher().

2.2. Classe Fichier

Créer une classe Fichier qui hérite de Element.

  • Son constructeur reçoit le nom du fichier.
  • La méthode afficher() affiche le nom du fichier précédé de Fichier :.

2.3. Classe Dossier

Créer une classe Dossier qui hérite également de Element.

  • Son constructeur reçoit le nom du dossier.
  • Chaque dossier possède une liste contenu, initialement vide.
  • Créer une méthode ajouter(element) permettant d'ajouter un fichier ou un dossier.
  • Redéfinir afficher() afin d'afficher le nom du dossier puis chacun des éléments qu'il contient.

2.4. Construction de l'arborescence

Créer les objets nécessaires pour obtenir :

NSI
├── cours.pdf
├── programme.py
└── Images
    ├── arbre.png
    └── graphe.png

2.5. Question

Expliquer pourquoi la ligne suivante peut fonctionner aussi bien pour un objet Fichier que pour un objet Dossier :

element.afficher()

Quel concept de programmation orientée objet est utilisé ici ?

3. Corrigé

3.1. Classe mère

class Element:
    def afficher(self):
        pass

3.2. Classe Fichier

class Fichier(Element):
    def __init__(self, nom):
        self.nom = nom

    def afficher(self):
        print("Fichier :", self.nom)

3.3. Classe Dossier

class Dossier(Element):
    def __init__(self, nom):
        self.nom = nom
        self.contenu = []

    def ajouter(self, element):
        self.contenu.append(element)

    def afficher(self):
        print("Dossier :", self.nom)

        for element in self.contenu:
            element.afficher()

3.4. Construction de l'arborescence

cours = Fichier("cours.pdf")
programme = Fichier("programme.py")

arbre = Fichier("arbre.png")
graphe = Fichier("graphe.png")

images = Dossier("Images")
images.ajouter(arbre)
images.ajouter(graphe)

nsi = Dossier("NSI")
nsi.ajouter(cours)
nsi.ajouter(programme)
nsi.ajouter(images)

nsi.afficher()

Affichage obtenu :

Dossier : NSI Fichier : cours.pdf Fichier : programme.py Dossier : Images Fichier : arbre.png Fichier : graphe.png

3.5. Explication du polymorphisme

Dans la boucle :

for element in self.contenu:
    element.afficher()

la variable element peut désigner un objet de la classe Fichier ou de la classe Dossier.

Python appelle automatiquement la méthode afficher() correspondant à la classe réelle de l'objet. Il s'agit de polymorphisme.

Le pattern Composite fonctionne précisément grâce à cette idée : un fichier et un dossier sont tous les deux considérés comme des Element.

3.6. Remarque sur la récursivité

Si un dossier contient un autre dossier, l'appel :

element.afficher()

peut déclencher à son tour une nouvelle boucle sur le contenu de ce sous-dossier. La structure est donc naturellement récursive.
